  2. Anote o nome exato de cada arquivo (ex: oferta1.jpg).
  3. Escreva abaixo um nome por linha e gere a configuração:
  1. Copie o texto gerado, abra o arquivo config.js no GitHub (ícone ✏️ lápis), apague tudo, cole e toque Commit changes.
  2. Em 2 a 5 minutos a tela atualiza sozinha. ✅

🏪 Ofertas por tienda

  1. Sube las imágenes a la carpeta img en GitHub (Add file → Upload files).
  2. Escribe una línea por anuncio así:
    Tienda | Teléfono | archivo | Título
    El teléfono puede quedar vacío.
  1. Copia el texto, abre config.js en GitHub (✏️), borra todo, pega y toca Commit changes.
  2. En 2 a 5 minutos la tela y las ofertas se actualizan. ✅
